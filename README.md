# Agentic Healthcare Insurance Claims & Prior Authorization Platform

AWS-native agentic AI platform for healthcare insurance workflows including benefits verification, policy retrieval, prior authorization, claims analysis, and appeals.

> 🚧 **Status:** Active Development

## Technologies

Python, OpenAI Agents SDK, OpenAI Responses API, AWS Bedrock AgentCore, MCP, FastAPI, Pydantic, RAG, Amazon S3, Textract, OpenSearch, Lambda, Step Functions, SQS, EventBridge, DynamoDB, Aurora PostgreSQL, CloudWatch, OpenTelemetry, Docker, Terraform, and GitHub Actions.

## Core Architecture

- Supervisor and specialized AI agents
- MCP-based enterprise tools
- Insurance-policy RAG
- AWS event-driven processing
- Deterministic Step Functions workflows
- Human-in-the-loop controls
- AI observability and evaluation
- Infrastructure as Code

## Planned Workflows

- Benefits verification
- Policy retrieval
- Prior authorization
- Claims analysis
- Appeals assistance
- Human review and escalation

## Important

This repository is under active development. Only synthetic or properly de-identified healthcare data should be used.
